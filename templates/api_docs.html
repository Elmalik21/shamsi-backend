Shamsi Smart API Documentation

RESTful API for Solar Energy Decision Support System in Egypt

Version: 1.0.0
Quick Start

Base URL: http://your-domain.com/api/v1/

Response Format: All endpoints return JSON

For local development: http://localhost:8000/api/v1/

Available Endpoints

GET
/api/v1/locations/

Retrieve all locations with solar potential data

// Request
GET /api/v1/locations/?governorate=Cairo&solar_potential__gte=70

// Response
{
    "count": 25,
    "next": null,
    "previous": null,
    "results": [
        {
            "id": 1,
            "name": "Cairo Downtown",
            "governorate": "Cairo",
            "latitude": 30.0444,
            "longitude": 31.2357,
            "solar_potential_score": 85,
            "avg_solar_radiation": 5.8
        }
    ]
}
GET
/api/v1/climate-data/

Retrieve climate data with filtering options

// Request
GET /api/v1/climate-data/?location_id=1&start_date=2024-01-01&end_date=2024-01-31

// Response
{
    "count": 31,
    "data": [
        {
            "date": "2024-01-01",
            "solar_radiation": 5.2,
            "temperature": 18.5,
            "humidity": 45,
            "dust_index": 0.3
        }
    ]
}
POST
/api/v1/solar-analysis/

Perform solar potential analysis for a location

// Request
POST /api/v1/solar-analysis/
{
    "location_id": 1,
    "analysis_type": "annual",
    "parameters": {
        "system_size": 5.0,
        "panel_efficiency": 0.18
    }
}

// Response
{
    "location_name": "Cairo Downtown",
    "annual_energy_yield": 8760,
    "solar_potential_score": 85,
    "recommendations": [
        "Excellent location for solar installation",
        "Recommended system size: 5-7 kW"
    ],
    "estimated_roi": 4.5
}
GET
/api/v1/export/climate-data/csv/

Export climate data as CSV file

// Request
GET /api/v1/export/climate-data/csv/?location_id=1&format=csv

// Response (CSV File Download)
date,solar_radiation,temperature,humidity
2024-01-01,5.2,18.5,45
2024-01-02,5.3,19.1,44
...
Authentication

Currently, most endpoints are publicly accessible. For future implementation:

  • JWT Token-based authentication
  • User roles: Admin, Company, Customer, Researcher
  • Rate limiting per API key
Authentication will be required for write operations and sensitive data.
Ready for React Integration

This API is fully prepared for React frontend integration:

  • CORS enabled for cross-origin requests
  • JSON responses optimized for React state management
  • Pagination support for large datasets
  • Error handling with consistent response format
React Example:
// React component fetching data
import React, { useEffect, useState } from 'react';
import axios from 'axios';

const LocationsList = () => {
    const [locations, setLocations] = useState([]);
    
    useEffect(() => {
        axios.get('http://localhost:8000/api/v1/locations/')
            .then(response => setLocations(response.data.results))
            .catch(error => console.error('Error:', error));
    }, []);
    
    return (
        

            {locations.map(location => (
                

                    
{location.name}

                    
Solar Potential: {location.solar_potential_score}%

                

            ))}
        

    );
};
